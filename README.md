# My-projects
A collection of my academic and personal projects built during my Computer Science engineering. Projects with clear documentation and source code.

## Student Record Management System (C)
A menu-driven student record system aligned with MSBTE topics (structures, arrays, file handling, searching, and sorting).

### Features
- Add, delete, search students
- Update marks
- Display all records
- Sort by ID or Name
- Persistent storage in a text file

### Build & Run
```bash
gcc student_record_management_system.c -o student_records
./student_records
```

Data is stored in `students.txt` in the same directory.
